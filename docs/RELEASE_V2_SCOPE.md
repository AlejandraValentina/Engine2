# Release v2.0 scope (frozen)

Este documento define el unico scope congelado para la release v2.0.

## Entregables exactos v2.0
1) Acople 0D->1D bidireccional (Wave Scope v1)
2) Sintesis multi-cilindro verificada (audio)
3) Barridos automaticos sin GUI (sweep headless)
4) Reporte/cut-list reproducible por CLI
5) Cobertura de regresion para presets legacy (marker `legacy`)

## Regla de scope
No se aceptan features nuevas fuera de esta lista; solo bugfix/coverage.

## Definition of Done (por item)
- Test o comando reproducible.
- Evidencia actualizada en `internal/FEATURES.md`.
- Docs minimas actualizadas.
- Runtime razonable.
